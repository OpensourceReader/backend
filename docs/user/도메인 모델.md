### User 도메인 제한사항
1. providerId가 존재하지 않는 유저는 이슈, PR 생성 등의 작업에 제한이 존재한다.
2. disabled가 활성화되고 90일이 지난 경우에는 해당 유저를 삭제해야한다.

### 도메인 모델 세부
#### User
- **속성**
    - id(Long): 개인 식별자 키
    - createdAt(Instant): 만들어진 시간
    - updatedAt(Instant): 최근 업데이트한 시간
    - providerId(String): Oauth2로 회원가입 시 제공되는 리소스 서버 id번호(고유함)
    - role(Role): 유저가 가진 권한
    - username(String): 유저가 가진 이름
    - nickname(String): 유저 개인 식별 닉네임(고유함)
    - email(String): 유저 개인 식별 이메일(고유함)
    - password(String): 유저 개인 패스워드(인코딩 되어야 함)
    - avatarUrl(String): 깃허브 연동 시 설정되는 깃허브 이미지 url
    - disabled(Boolean): 휴면 혹은 삭제 시 disabled는 활성화됨

- **행위**
    - updateAvatar(String newAvatarUrl): 새 아바타 url를 집어넣는다.
    - linkSocialProvider(String newProviderId): 새 소셜 providerId를 집어넣는다.
    - T updateField(T target, T replace): 업데이트 메서드, 두 값을 비교해서 적절한 값을 반환한다.
