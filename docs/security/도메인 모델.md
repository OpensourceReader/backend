# 보안 도메인 모델

## 목표
- 유저를 생성한다.
- 로그인 시 JWT 토큰을 건네준다.
- 비인증된, 비인가된 접근을 막는다.

## 전체 도메인 구성
1. RefreshToken
2. Auth

### RefreshToken 도메인
1. 닉네임을 통해 토큰을 만들 수 있다.
2. 만료될 경우, 삭제한다
3. 닉네임을 통해 토큰을 무효화시킬 수 있다.
4.

1. 유저가 의도적으로 자신의 토큰을 삭제시킬 수 없다.

### 도메인 모델 세부
#### RefreshToken
- **속성**
    - id(Long): 개인 식별키
    - createdAt(Instant): 생성일
    - updatedAt(Instant): 업데이트 시간(추후 삭제할 가능성 존재)
    - user(User): id를 통해 단방향(RefreshToken -> User, 의존관계 주인: RefreshToken)으로 연결
- **행위**
  - isExpired(): 현재 Instant.now()와 비교, 현재 값이 Instant.now()보다 작으면 만료 시간이 지남
